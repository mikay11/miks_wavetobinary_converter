6. Explain It

Q1. Why does the time of each sample use i ÷ n instead of the frequency?

We are sampling one full wave, spread evenly over its period. The sample position i ÷ n is just the fraction of the way through that wave (0, 1/n, 2/n ... up to (n-1)/n). Multiplying that fraction by the period gives the real time. This keeps the samples evenly spaced across the wave no matter what the frequency is, so the frequency only sets the period and wavelength, not the shape of the sampled wave.

Q2. What does the level of a sample represent?

The level is the sample's height quantized onto a fixed number of steps. The height runs from -1 to +1, but a digital system can only store a limited number of values. There are 2bits levels, numbered 0 up to levels-1. The formula (height + 1) ÷ 2 × (levels - 1) maps the -1 to +1 range onto those step numbers, and rounding picks the nearest step. For example, with 2 bits (4 levels, numbered 0-3) a height of 0 lands on level 2.

Q3. Why must every binary value have exactly "bits" digits with leading zeros?

Each sample is stored in a fixed number of bits, like a fixed-width slot in memory. Writing 2 as 010 (3 bits) keeps every sample the same width so the totals add up: samples × bits. If we dropped the leading zeros, 0, 1 and 10 would look like different sizes, the bit count would be wrong, and a computer reading the stream would not know where one sample ends and the next begins.

Q4. Why do we round up when a height lands exactly halfway between two levels?

A halfway value is a tie, and ties need one consistent rule so the same input always gives the same output. We choose "round up" (toward the higher level) as a simple, predictable standard. Without a rule, different roundings would make the binary result unpredictable and could make a rebuilt wave differ from the original.
